# Teethy tooth library

The tooth sets in this folder (set-01.ptl to set-09.ptl) are the anterior tooth library from
[teethy.org](https://teethy.org), redistributed in Pare 3D with the written permission of its owner.
They are converted to Pare 3D's compact tooth-set format (src/lib/toothLibrary.ts) by
tests/tools/buildToothLibrary.tool.ts: simplified to within 0.01 mm of the original surface, each
tooth still a closed shell.

The permission covers Pare 3D. Anyone redistributing these files outside Pare 3D should check
teethy.org's own terms.
